# 🎓 UniSkill Exchange — Peer Skill Sharing & Task Platform

**UniSkill Exchange** is a single-page, web-based peer-to-peer skill-sharing platform designed specifically for university students (e.g., Gazipur Digital University). It enables students to learn from each other, offer mentorship, complete task requests, collaborate on real-world projects, and earn virtual currency (**UniCoins**) to build their academic and skills reputation.

---

## ✨ Key Features

- 👤 **Interactive Student Onboarding & Authentication**: Multi-step registration, email verification demo, and initial skill profiling.
- 🔍 **Peer Discovery & Smart Skill Matching**: Algorithmically matches students based on skills they want to learn and skills they can teach.
- 📋 **Task Marketplace & Lifecycle**: Post requests for help (code debugging, design, presentation tips), set UniCoin rewards, and track task progress through stages.
- 🙋 **Learning Requests & Mentorship**: Public board for requesting peer tutoring or specialized skill guidance.
- 🚀 **Project Collaboration Hub**: Team up for club activities and research projects with automated role-based member recommendations.
- 💬 **In-App Messaging**: Peer-to-peer chat interface for instant communication and skill exchanges.
- 🏆 **Gamified Reputation System**:
  - **UniCoins Wallet**: Virtual currency earned by helping peers.
  - **Rank Progress**: Progression from Bronze to Diamond based on activity.
  - **Badges**: Achievements like *First Contribution*, *Problem Solver*, and *Community Champion*.
  - **Leaderboard**: Displays top student contributors in real time.
- 📊 **Built-in Presentation/Demo Mode**: Interactive slide deck presentation embedded directly into the application for project showcases.
- 🌓 **Dark/Light Mode**: Full responsive design with customizable theme toggle.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern CSS3 (CSS Variables, Responsive Grid/Flexbox)
- **UI Framework**: React 18 (Loaded directly via CDN - Standalone UMD)
- **Icons & Fonts**: Google Fonts (Fraunces, Public Sans, IBM Plex Mono)
- **State Management**: React Hooks (`useState`, `useMemo`, `useRef`, `useEffect`)
